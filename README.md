# Análise de Dados de Vendas com Python

Projeto desenvolvido para analisar dados anuais de vendas de uma empresa de varejo, utilizando Python e SQLite.

## Objetivo

Transformar registros de vendas em informações úteis, identificando o faturamento total, o desempenho das categorias, a evolução mensal e os produtos com maiores e menores vendas.

## Tecnologias utilizadas

- Python
- SQLite
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Análises realizadas

- Tratamento e verificação dos dados
- Cálculo do faturamento total e da média de vendas
- Análise de vendas por categoria
- Análise da evolução mensal
- Identificação dos produtos com maior e menor faturamento
- Criação de gráficos para visualização dos resultados
- Validação dos resultados com testes automatizados

## Principais resultados

A análise permitiu observar o desempenho das vendas ao longo do ano, comparar o faturamento das categorias e identificar os produtos com maiores e menores valores de venda.

## Como executar

1. Clone este repositório.
2. Abra a pasta do projeto no VS Code.
3. Crie e ative um ambiente virtual.
4. Instale as dependências:

```bash
pip install -r requirements.txt
```

5. Abra o arquivo `analise_vendas.ipynb`.
6. Selecione o ambiente virtual como kernel.
7. Clique em **Run All** para executar todas as células.

O banco de dados `dados_vendas.db` será criado automaticamente durante a execução.

## Estrutura do projeto

- `analise_vendas.ipynb`: notebook principal da análise
- `requirements.txt`: bibliotecas necessárias para executar o projeto
- `.gitignore`: arquivos que não serão enviados ao GitHub
- `README.md`: apresentação e instruções do projeto
